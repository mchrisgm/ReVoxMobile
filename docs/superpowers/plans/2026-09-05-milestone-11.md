# Milestone 11 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. This plan is split into one file per lane under `2026-09-05-milestone-11/`; each lane was executed by its own worker in its own git worktree and merged in the order below.

**Goal:** The owner's fourth round. A Live screen whose controls are grouped by what they do (Listen, Voice, Languages) with the two-way pair named as *You speak* / *They speak*; a word popover in Learning mode (tap a word as spoken, see how it sounds, what it means and the sentence it came from); phrases the gates were unsure about kept and greyed instead of dropped, with a Settings toggle to drop them; the History Merge / Delete bar above the tab bar instead of under it; an on-device benchmark of the translation models that turns the memory-tier recommendation into a measured one; and a tutorial that shows the new screens.

**Architecture:** Every decision that can be tested without Apple frameworks lands in `ReVoxCore` and is proven by `swift test` on Linux before app code is written: the gate outcome that marks a guess (`SpeechGate.classify`), `Translation.isGuess` through the pipeline and the transcript formatter, the word-error rate and the benchmark record, verdict and report, and `DeviceRecommendation.measured`. The app layer adds SwiftUI surfaces over those: captioned pill groups behind a `LiveControlsModel` protocol, a `WordFlowLayout` of tappable chips with one popover per row, the Benchmark screen, the History bar as a bottom safe-area inset. CI on the iPhone simulator is the compiler for the app targets; nothing app-side is claimed to build until a run says so.

**Tech Stack:** Swift 5 language mode, iOS 17 (Translation framework weak-linked, used through `#available(iOS 18)`), SwiftUI, SwiftData, NaturalLanguage, AVFoundation, XCTest; `ReVoxCore` is Foundation-only.

**Spec:** `docs/superpowers/specs/2026-09-05-milestone-11-design.md`. Sections are cited as §.

## Global Constraints

- Branch `claude/revoxmobile-ios-app-hkajbf` from `main`; PR into `main`; merge only when the CI run on the head is green.
- `ReVoxCore` imports only Foundation; `swift test --package-path ReVoxCore` must pass on Linux.
- App-target files are checked locally with `swiftc -parse` only; the gates `scripts/dev/check-core-imports.py --all`, `check-test-autoclosures.py`, `check-tests-are-discoverable.py`, `scripts/ci/check-constant-coverage.sh`, `check-no-host-time.sh` run before every push.
- Every new ported-style constant is asserted in a test and listed in `scripts/ci/check-constant-coverage.sh`.
- Settings keys are snake_case; a pre-M11 `settings.json` decodes with `keep_guesses` at its default (true). A pre-M11 SwiftData store migrates with `isGuess` false on every row.
- The broadcast extension is untouched.
- No model identifiers in any committed artifact.

## Lane L8: the integration check's unowned items

A cross-lane consistency check ran over the seven plans after wave 1 merged. Its compile-blocking finding (L5 was written against the pre-merge L4 signatures) was applied by the L5 worker, which read the merged L4 files. Three items belonged to no lane and became L8:
