# Milestone 9 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Eight owner-reported fixes and improvements: keep the chosen model when the iPhone is hot, quick controls on the Live screen with a new *Very fast* latency preset, merging sessions in History, a Learning mode (original text above the translation, with romanization), relative age on Live rows, an example for every setting, a whole-row highlight for the selected model, and the click before every pocket-tts phrase.

**Architecture:** Every decision that can be tested without Apple frameworks lands in `ReVoxCore` (the thermal policy input, the preset, the romanizer, the relative-age text, the clip-head gate, the merge ordering) and is proven by `swift test` on Linux before any app code is written. The app layer wires settings to those decisions and adds SwiftUI surfaces. CI on the iPhone simulator is the compiler for the app targets; nothing app-side is claimed to build until a run says so.

**Tech Stack:** Swift 5 language mode, iOS 17, SwiftUI, SwiftData, XCTest; `ReVoxCore` is Foundation-only.

**Spec:** the owner's milestone request (session `session_017rNMt2Xns5wUvUYmLHyjKR`), quoted per task below. Design spec sections cited as §.

### Task 4: ClipHead (core) and pocket-tts (app)

Owner: "a small artifact every time right before the saying 'This is ReVox'". M4 measurement row 20 recorded this on build 13; the 5 ms edge ramp added then did not settle it. The owner still hears it, so whatever it is survives a 5 ms ramp: it is longer than 5 ms, or it precedes the speech by more than that.

**Files:** NEW `ReVoxCore/Sources/ReVoxCore/ClipHead.swift`, `ClipHeadTests.swift`; modify `ReVoxMobile/Speech/PocketTTSSpeaker.swift`; `docs/measurements/m4-pocket-tts-ducking.md` row 20.

**Produces:**
```swift
public enum ClipHead {
    public static let windowFrames = 48        // 2 ms at 24 kHz
    public static let sustainWindows = 4       // 8 ms of speech before it counts as the onset
    public static let onsetRatio: Float = 0.05 // of the clip's peak
    public static let leadFrames = 240         // 10 ms kept ahead of the onset, ramped in
    /// Everything before the first sustained speech is dropped; the 10 ms ahead of it is ramped in.
    public static func conditioned(_ samples: [Float], sampleRate: Int) -> [Float]
    public static func onset(of samples: [Float], sampleRate: Int) -> Int?
}
```
- [ ] Tests: a 3 ms full-scale click at frame 0 followed by 40 ms of silence then 200 ms of a 0.5-amplitude tone → onset is inside the tone, the click is gone, output starts with a ramp whose first frame is 0; a clean tone from frame 0 → at most `leadFrames` removed and `abs(first) == 0`; a DC offset of 0.3 for 50 ms before a tone → removed; silence only → returned unchanged; a clip shorter than `leadFrames * 2` → unchanged.
- [ ] Implement: peak; walk windows; first run of `sustainWindows` consecutive windows whose peak ≥ `onsetRatio * peak` is the onset; `start = max(0, onset - leadFrames)`; result = `samples[start...]` with a linear ramp over the first `leadFrames`.
- [ ] `PocketTTSSpeaker.synthesize`: `let conditioned = ClipHead.conditioned(samples, sampleRate: sampleRate)`; log `pocket-tts head trimmed_ms=…` at info in the measurements category.
- [ ] Measurement row 20: build 22+, what to listen for, and the log line.
- [ ] Commit.
