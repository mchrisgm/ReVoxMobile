# Security review — milestone 5 (broadcast bridge)

Scope: design spec §7 (extension) and §11 (security and privacy) on branch `milestone/5-broadcast-capture`.

Two passes. The first was performed by the `security-auditor` agent over the scope below; I ran it because I had checked the enabled claude.ai skill list rather than the tool registry and wrongly concluded the `security-review` skill the plan names was unavailable. The second pass was that skill, run afterwards over the same branch with the first pass's findings as prior art. Both are recorded here. Three automated gates — `scripts/ci/check-extension-surface.sh`, `scripts/ci/check-plists.py` and `scripts/ci/check-broadcast-bridge-doc.py` — pass on this branch.

The second pass confirmed the first: it re-derived clean results for the ring's memory safety (the two-part copy is bounded on the layout, never the header; `mmap` is preceded by an `fstat` and a size refusal; `MAP_FAILED` is correctly detected), for the record deserialization (a fixed `Codable` struct through `PropertyListDecoder`, no `NSKeyedUnarchiver`, no class-graph decoding), for the untrusted `CMSampleBuffer` path through `BroadcastConverter`, and for the manifests, entitlements and CI gates. It found **one** issue the first pass missed, listed as finding 16.

**Outcome: no blocking findings.** There is no network, no keychain, no credential and no remotely reachable surface in milestone 5, so nothing here is remotely exploitable. Eight should-fix findings — reachable traps, an availability flood, and privacy-at-rest — were all fixed on this branch with tests. Seven notes are recorded below with an owner.

## Findings

| Id | Severity | Where | Finding | Disposition |
|---|---|---|---|---|
| 1 | should-fix | `RingReader.swift` | A cursor ≥ 2^63 in the shared page traps `Int(_:)`. The header has no checksum, so one flipped bit passes the magic and geometry checks; the file persists, so the trap is a crash on every launch until the app is deleted. `reader.header` force-unwrapped `RingHeader.read`, which is nil on a corrupted magic. | **Fixed** — `maxPlausibleCursor`, `Int(clamping:)`, optional `header`; 2 tests. |
| 2 | should-fix | `RingReader.swift`, `SileroVAD.swift` | One non-finite sample poisons the VAD's LSTM state permanently: `probability >= threshold` is false for NaN, so no phrase is ever detected again and nothing reports an error. `Segmenter.reset()` runs once per pipeline start, so the run stays silently dead. Reachable from any app the user chooses to broadcast. | **Fixed** — sanitised in `RingReader.read`; VAD drops a poisoned state and returns 0; 2 tests. |
| 3 | should-fix | `RingReader.swift`, `BroadcastCapture.swift`, `BroadcastCoordinator.swift` | The freshness test was one-sided. A backwards clock step makes a dead broadcast look live, and `probe()` then starts the pipeline unattended and speaks residual ring audio. | **Fixed** — `RingHeader.isHeartbeatFresh(now:)`, one method behind all three sites; 2 tests. |
| 4 | should-fix | `SampleHandler.swift` | Up to 60 s of the decoded audio of the last broadcast stayed in the ring file until the *next* broadcast, which may never come. | **Fixed** — zeroed on `broadcastFinished` and on failure. §11 and the App Review note in `docs/release.md` updated to say "start and end". |
| 5 | should-fix | `BroadcastSession.swift` | `annotatedBundleID` — the most disclosing value in the bridge — was retained indefinitely in the App Group plist, which is **not** backup-excluded. | **Fixed** — cleared by `finished()` and `failed()`; 1 test. |
| 6 | should-fix | `DarwinNotificationObserver.swift`, `BroadcastCapture.swift`, `BroadcastCoordinator.swift` | Any app can post the six names (the App Group id ships in the Info.plist). Each `started`/`stopped` post cost a plist decode **and an `mmap` of 3.84 MB on the main actor**; both observer streams buffered unbounded. A battery/responsiveness attack from outside the sandbox. | **Fixed** — `bufferingNewest(1)`, wake polls coalesced to 10 ms (timer ticks untouched), one cached mapping in the coordinator, wake log at `.debug`; 1 test. `docs/broadcast-bridge.md` §6 corrected. |
| 7 | should-fix | `KeepAliveMonitor.swift` | `logHandle?.write(Data(...))` resolves to the legacy overload, which raises an Objective-C exception Swift cannot catch — a full disk terminates the app on every heartbeat. Plus: no rotation (~3.4 MB/day of use), no protection class, and included in iCloud backups. Differenced at 1 Hz the file is a timestamped record of when the user was translating. | **Fixed** — `try? write(contentsOf:)`, truncate on `reset()` and a 512 KB cap, protection class and per-file backup exclusion. |
| 8 | should-fix | `SampleHandler.swift` | `String(describing: error)` at `privacy: .public` renders a `CocoaError`'s `NSFilePath` — the App Group container path — into a log that leaves the device in every sysdiagnose. | **Fixed** — `describe(_:)` returns a case name plus errno. |
| 9 | note | `BroadcastStateRecord.swift` | `contractVersion` and `ringFile` are written but never read. A future v2 record happens to fail safely (a missing non-optional key yields nil), but by accident. | **M7** — reject a record whose `contractVersion != 1` or `ringFile != RingLayout.fileName` before its `generation` is used. |
| 10 | note | `BroadcastCoordinator.swift` | `finishReason` is interpolated into the UI unbounded. Written only by the extension today, and SwiftUI `Text` interprets no markup, so this is a layout concern only. | **M7** — cap at 200 characters if the App Group's contract ever widens. |
| 11 | note | `RingBridge.swift` | `RingHeader.read` guards on `Offset.reservedStart` (172), not `headerBytes` (4096). Harmless today because `map` always maps exactly `totalBytes`. | **M7** — tighten the guard to the invariant it protects. |
| 12 | note | `RingFileMapping.swift` | Backup exclusion is `try?` and silent. If it fails, 60 s of third-party audio goes to iCloud with no signal. | **M7** — log the failure and re-verify the flag on the next `openCreating`. |
| 13 | note | `RingFileMapping.swift` | The protection class is applied at creation only. A file created by an older build, a test helper or a restored backup never gets it upgraded. | **M7** — re-assert with `setAttributes` on every `openCreating` (idempotent, one call). |
| 14 | note | `BroadcastCapture.swift` | The `selfcapture` line logs audio-derived amplitudes at `.public`. Far too coarse to reconstruct speech, but it is measurement instrumentation. | **M7** — delete or move behind a debug flag once `docs/measurements/m5-broadcast-capture.md` rows 6–7 are filled. |
| 16 | should-fix | `ReVoxMobile/Capture/DarwinNotificationObserver.swift` | The observer registered itself with `Unmanaged.passUnretained(self)`. CF invokes callbacks *outside* its own lock, so `RemoveEveryObserver` returning does not un-invoke one already in flight — and `BroadcastCapture.stop()` deregisters and deallocates from a cooperative-pool thread while delivery happens on the main run loop. A co-resident app posting the (publicly derivable) names in a loop widens that window at will. `BroadcastCoordinator` was never exposed, being `@MainActor`. | **Fixed** — CF now holds a small context box registered `passRetained` and never released, so the pointer is valid for the life of the process; `stop()` invalidates it, making a late delivery a no-op. 1 test. |
| 17 | note | `RingReader.swift`, `Shared/Broadcast/BroadcastSession.swift` | Two integer-overflow traps of finding 1's class that its fix did not reach: `overrunCount` is seeded from the shared page and incremented, and `BroadcastSession.init` does `previousGeneration + 1` on a generation read from the header with no plausibility bound. Both trap at `UInt64.max`, and both values persist, so the crash repeats. Corruption-triggered, not attacker-triggered. | **M7** — bound both the same way `maxPlausibleCursor` bounds the cursor. |
| 18 | note | `ReVoxMobile/Capture/BroadcastCapture.swift` | Finding 5's fix has a hole: `markLost` rewrites the record with `state = .lost` but does not clear `annotatedBundleID`, so the bundle id survives the path where ReplayKit never calls `broadcastFinished` (the extension was killed). | **Fixed** (App Store readiness) — cleared in `markLost` too; `BroadcastCaptureTests.testStaleHeartbeatMarksTheRecordLost` covers it. |
| 15 | note | `scripts/ci/check-plists.py` | The app manifest is validated non-exactly (`exact=False`), so the app may declare categories nothing uses; the extension gets the strict treatment. | **M7** — extend `exact=True` to the app once its API set is stable. |

### Note 7 (carried, and now larger than it was)

The M7 grep gate `scripts/ci/check-no-host-time.sh` does not exist yet. Two requirements for it, both from this review:

1. **Scope.** Its planned scan list (`ReVoxMobile ReVoxMobileTests ReVoxBroadcast ReVoxCore`) must gain `Shared`, a top-level source root compiled into both targets that did not exist when the gate was specified. It must also cover `ReVoxMobile/Capture`, which the nearest existing check (`check-extension-surface.sh`) does not scan.
2. **Pattern.** The existing pattern (`hostTime|mach_absolute_time|mach_continuous_time|systemUptime`) would not catch `CACurrentMediaTime()` — the wrapper an engineer is most likely to reach for — nor `ContinuousClock`, `SuspendingClock`, `DispatchTime.now()`, `clock_gettime(CLOCK_UPTIME_RAW)` or `CMClockGetHostTimeClock`. `ContinuousClock` is already a live idiom in this codebase (`PocketTTSSpeaker`), so this is not hypothetical.

The consequence of a miss is a required-reason API with no manifest entry, which `check-plists.py` forbids and Apple rejects at submission.

## Residual risks accepted for v1

- Any process carrying the same App Group entitlement — only ReVox's own two targets, bound to the team — can read the ring. The App Group is the trust boundary Apple provides.
- `.completeUntilFirstUserAuthentication` leaves the ring readable after the first unlock. It is the only class an extension that must run after a later lock can use. The exposure is now bounded by zeroing on both edges of a broadcast rather than only on the leading one.
- The Darwin names are guessable from the shipped Info.plist. A foreign post cannot start the pipeline, read anything, or write anything; after finding 6 its cost is one coalesced poll.
